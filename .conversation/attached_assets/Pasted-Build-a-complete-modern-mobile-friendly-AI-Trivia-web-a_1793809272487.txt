Build a complete, modern, mobile-friendly AI Trivia web application.

Tech stack: Use a suitable web framework supported by Replit. Implement a secure backend for API requests.

1. Public API

• Fetch real trivia questions from the Open Trivia DB API: https://opentdb.com/api.php?amount=1&type=multiple
• Display the question and four shuffled answer options.
• Decode HTML entities in the returned text.
• Let the user select an answer and check whether it is correct.
• Include a button to load another question.

2. OpenRouter AI

• Connect to OpenRouter through a server-side API endpoint.
• Read the API key from the OPENROUTER_API_KEY environment secret.
• Use a configurable supported model.
• Send the trivia question, the user’s selected answer, and the correct answer to the AI.
• Ask the AI to explain the correct answer in simple, friendly English in 2–4 sentences.
• Display the generated explanation in a dedicated card.
• Never expose the API key in frontend code.

3. Error handling

• Handle failed public API requests, network errors, invalid responses, OpenRouter authentication errors, rate limits (429), and server errors.
• Show friendly, understandable messages and a retry button.
• Do not show raw stack traces or sensitive information to users.

4. Loading states

• Show a loading indicator while fetching a question.
• Show a separate loading indicator while waiting for the AI explanation.
• Disable relevant buttons while requests are in progress.

5. UI and accessibility

• Create a polished, modern quiz interface with a clear heading, question card, four answer buttons, score indicator, AI explanation card, and next-question button.
• Make it responsive on mobile, tablet, and desktop.
• Use readable typography, accessible contrast, visible focus states, and comfortable touch targets.
• Include success and incorrect-answer feedback.

6. Final checks and deployment

• Test the API integrations and error states.
• Add clear setup instructions for the OPENROUTER_API_KEY secret.
• Add any required dependencies and a README.
• Run the application, fix any errors, and ensure it works on mobile.
• Prepare it for Replit publishing and explain how to publish it and obtain the public URL.

Do not hardcode API keys. Do not claim an integration works unless it has been tested. Build the actual working application, not just a mockup.
